Como gerar o token (só precisa fazer isso uma vez):
1. No GitHub, clica na sua foto (canto superior direito) → Settings
2. Desce até "Developer settings" (no menu esquerdo, bem embaixo)
3. "Personal access tokens" → "Tokens (classic)" → "Generate new token (classic)"
4. Marca a caixinha "repo" (dá acesso completo aos repositórios)
5. Clica em "Generate token" e copia o código que aparece (começa com "ghp_") — cola ele aqui em cima
